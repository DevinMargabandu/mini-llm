Interpretation: torch.autocast(bf16) is not faster than fp32 on this MPS backend
for these model/batch sizes -- MPS does not currently give bf16 matmuls a
hardware throughput advantage the way NVIDIA Tensor Cores do, so autocast here
mostly adds dispatch/cast overhead. The same autocast code path gives the
classic mixed-precision speedup on CUDA hardware (fp16 with GradScaler, or
bf16 on Ampere+), which this benchmark script also supports -- it just wasn't
run on that hardware for this project.
